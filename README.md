# MatteID — privacy, terms and support

These pages are **generated** from MatteID's own string catalogue
(`shared/localization/ui-strings.json`) by `scripts/build-legal-site.py` in the app repository.
Do not edit them by hand: the next generator run discards the change, and a hosted privacy policy
that disagrees with the one inside the app is worse than either copy alone.

The privacy policy and terms of use are published in all 70 languages the app speaks. English is
at the root; every other language sits under its own locale code.
